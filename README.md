# 15 Minutes Magdeburg
This project was developed by a team of five people from [Netz39 e.V.](https://netz39.de) as during the ["Smart City Hackathon Magdeburg 2026 (5–6 June)"](https://beteiligung.sachsen-anhalt.de/portal/magdeburg/beteiligung/themen/1003460). The hackathon was part of the [Tomorrow Labs](https://tomorrowlabs.magdeburg.de/) initiative.

The aim was to create a “Smart City” dashboard within 24 hours and then present a prototype to the jury and the audience in a short public pitch.


## Note on self-hosting
Unfortunately, the current version cannot be run entirely locally, as we rely on additional infrastructure that we hosted ourselves during the hackathon but which did not make it into this repository in time.

Furthermore, our code contains hard-coded URLs  in some places (please don’t do this), which makes self-hosting a little more difficult.
